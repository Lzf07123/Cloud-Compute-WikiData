# `权限与用户管理-w` 🔐 — 显示登录用户及活动

## 作用

w 显示当前登录用户、正在执行的命令以及系统负载信息，比 who 多了 CPU 使用率和当前命令。

## 语法

```
w [选项] [用户]
```

## 用法

w 一行显示：用户名、终端、来源、登录时间、空闲时间、JCPU、PCPU、当前命令。`-h` 不显示标题，`-s` 短格式，`-i` 显示 IP。指定用户名可只查看该用户。快速了解系统活跃度的工具。

## 常用参数

| 参数 | 说明         |
| ---- | ------------ |
| `-h` | 不显示标题行 |
| `-s` | 短格式       |
| `-i` | 显示 IP      |
| `-o` | 旧格式       |

## 示例

```bash
w                         # 显示用户及正在运行的命令
w -h                      # 不显示标题行
w -s                      # 短格式输出
w ALICE                   # 只查看用户 ALICE
```
