# `系统管理-man` 🖥️ — 查看命令手册

## 作用

man（manual）是 Linux 的在线参考手册，提供命令、系统调用、库函数、配置文件等的详细文档。是学习和使用 Linux 命令最重要的帮助工具。

## 语法

```
man [选项] [章节] 命令
```

## 用法

man 以分页形式显示指定命令的帮助文档。按 `/关键词` 搜索，`n` / `N` 浏览匹配项，`q` 退出。`man 5 crontab` 查看指定章节。`-K 关键词` 在所有手册中搜索指定关键词；`-w 命令` 只显示手册文件路径；`-f 命令` 显示命令简短描述（whatis）。手册分多个章节：1 用户命令、2 系统调用、3 库函数、5 文件格式、8 系统管理命令。

## 常用参数

| 参数        | 说明                   |
| ----------- | ---------------------- |
| `-K 关键词` | 搜索所有手册           |
| `-w 命令`   | 显示手册路径           |
| `-f 命令`   | 显示简短说明（whatis） |
| `章节`      | 指定手册章节           |

## 手册章节

| 章节 | 内容         |
| ---- | ------------ |
| 1    | 用户命令     |
| 2    | 系统调用     |
| 3    | 库函数       |
| 5    | 文件格式     |
| 8    | 系统管理命令 |

## 示例

```bash
man ls                          # 查看 ls 命令的完整手册
man 5 crontab                  # 查看 crontab 文件格式（章节 5）
man -K KEYWORD                  # 在所有手册中搜索关键词
man -w ls                       # 只显示手册文件路径
```
